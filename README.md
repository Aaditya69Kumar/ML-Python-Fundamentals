Machine Learning Practice Tasks
This repository contains solutions to introductory machine learning   and Python programming tasks.
The goal of this practice is to strengthen fundamental programming skills and understand basic concepts used in data science and machine learning workflows.

 Learning Objectives
•	Apply basic Python programming concepts using loops and lists.
•	Understand the levels of intelligence in data science: Statistics, Artificial Intelligence, Machine Learning, and Deep Learning.
•	Perform basic data preprocessing, including:
o	Handling missing values
o	Imputing numerical and categorical data
o	Encoding categorical variables

 Tasks Overview
Task 1 – Sorting Using While Loop
Given a list:
arr = [2, 0, 1, 2, 0, 1]
A Python script is implemented using a while loop to sort the numbers such that:
0s come first → then 1s → then 2s
This task helps practice list manipulation and control structures.


Task 2 – Random Number Generation
In machine learning experiments, random data is often generated to test models.
A Python script using a for loop generates and prints:
•	10 random numbers
•	Range: 1 to 100
This demonstrates basic Python loops and random data simulation.

Task 3 – Levels of Intelligence in Data Science
A selected industry example explains how the following four levels contribute to real-world systems:
1.	Statistics – Data analysis and summarization
2.	Artificial Intelligence (AI) – Intelligent decision making
3.	Machine Learning (ML) – Learning patterns from data
4.	Deep Learning (DL) – Neural networks for complex tasks

Task 4 – Data Preprocessing
The provided dataset is loaded and processed to prepare it for machine learning models.
Steps performed include:
•	Handling missing values (NA)
•	Imputing numeric data
•	Handling categorical variables
•	Encoding categorical features
The goal is to create a clean, ML-ready dataset.
